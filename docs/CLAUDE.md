# docs/ — 문서

> 상위: [../CLAUDE.md](../CLAUDE.md) · 문서는 코드·결과가 바뀔 때 함께 갱신한다.

## 문서 지도
| 파일 | 내용 | 언제 고치나 |
|---|---|---|
| `progress.md` | 월별 경과 (장학금 중간/결과 보고서 근거). 새 항목은 위에 | **작업을 끝낼 때마다 날짜와 함께** |
| `research_summary.md` | 결과 요약 (감성 없이 무엇이 설명되는가) | 새 결과가 나왔을 때 |
| `file_index.md` | 폴더·파일 명단 | 파일/폴더 구조가 바뀔 때 (각 폴더 `CLAUDE.md`와 일치시킨다) |
| `deployment.md` | 호가창 수집기 VPS/로컬 배포·점검·백업 절차 | 배포 절차가 바뀔 때 ([../deploy/CLAUDE.md](../deploy/CLAUDE.md)) |

## 규칙
- 주석·문서는 한국어. 수치는 `results/*/summary.md`의 값을 그대로 인용하고 출처 경로를 적는다
- 옛 탐색 단계 결과(`descriptive`, `horizons`, `eda_binance`)는 `archive/pre-restructure` 브랜치에 있다 — 인용 시 그 사실을 밝힌다
- 구조 안내가 겹치는 곳(루트 `README.md`, `CLAUDE.md` §6, `file_index.md`)은 서로 모순되지 않게 같이 고친다
