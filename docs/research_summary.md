## 4. 시간 단위별 분석 (`results/horizons/`)

### 4.1 평균회귀성

| 봉 크기 | 유동성 충격 반감기 (Amihud / λ / 변동성) | 수익률 1차 자기상관 (t값) |
|---|---|---|
| 5분 | 3.5분 / 1.3분 / 5.4분 | −0.028 (−27.2) |
| 15분 | 16분 / 6분 / 26분 | −0.011 (−5.9) |
| 1시간 | 1.3시간 / 0.5시간 / 1.8시간 | −0.026 (−7.2) |
| 4시간 | 4.3시간 / 2.2시간 / 4.9시간 | −0.022 (−3.1) |
| 1일 | 40시간 / 28시간 / 31시간 | −0.063 (−3.5) |

- 반감기가 봉 크기에 비례해 커진다 → 유동성은 **여러 시간 규모의 충격이 겹친 구조**(한 가지 속도로 사라지지 않음). HAR 구조(직전·하루·1주 평균)가 잘 맞는 이유
- 수익률은 **모든 시간 단위에서 다음 봉에 살짝 되돌려진다** (경제적 크기는 수수료보다 훨씬 작음)

**기술지표 신호의 되돌림** — 과매수·과매도 다음 봉 평균 수익률

| 신호 | 5분 | 15분 | 1시간 | 4시간 |
|---|:-:|:-:|:-:|:-:|
| RSI < 30 (과매도) | **+1.2bp** (t 4.6) | **+1.3bp** (t 2.1) | 0.0 | −2.7 |
| RSI > 70 (과매수) | 0.0 | +1.1 (t 2.5) | **+2.9** (t 2.3) | **+10.1** (t 2.7) |
| 볼린저 하단 이탈 | **+0.9** (t 5.4) | +0.9 (t 2.1) | +2.2 | −10.8 |
| 볼린저 상단 돌파 | −0.5 (t −3.7) | +0.5 | +2.4 | **+16.8** (t 4.4) |

→ **짧은 봉(5·15분)에서는 평균회귀**(과매도 후 반등), **긴 봉(1·4시간)에서는 추세 지속**(과매수 후 추가 상승). 교과서적 해석("과매수 = 매도")은 1시간 이상에서 반대로 작동. 단 크기가 수수료(10bp)보다 작거나 비슷하다.

### 4.2 예측 성능 — 유동성 vs 가격, 미시구조 vs 기술지표

**표본 외 R² (%)**

| 대상 | 모형 | 5분 | 15분 | 1시간 | 4시간 | 1일 |
|---|---|:-:|:-:|:-:|:-:|:-:|
| **Amihud** | 미시구조 (M2) | 35.4 | 27.2 | 22.8 | 32.9 | 4.6 |
|  | 기술지표만 (T1) | 24.0 | 6.1 | −5.5 | 3.9 | −26.8 |
|  | 결합 (C1) | 35.4 | 27.4 | 23.4 | 33.3 | 7.4 |
| **Kyle's λ** | 미시구조 (M2) | 47.4 | 43.5 | 40.9 | 40.4 | 30.6 |
|  | 기술지표만 (T1) | 46.3 | 40.1 | 35.0 | 35.1 | 17.9 |
|  | 결합 (C1) | 47.4 | 43.5 | 41.1 | 40.8 | 31.2 |
| **실현변동성** | 미시구조 (M2) | 33.8 | 24.0 | 20.0 | 34.8 | 33.9 |
|  | 기술지표만 (T1) | 7.9 | −32.9 | −35.1 | 13.6 | 11.6 |
|  | 결합 (C1) | 35.5 | 25.6 | 20.6 | 35.9 | 34.6 |
| **수익률** | 미시구조 (M2) | 0.02 | −0.03 | −0.19 | −0.17 | −0.70 |
|  | 기술지표 부스팅 (T2) | **0.23** | **0.19** | −0.12 | −0.66 | −0.78 |
|  | 결합 (C1) | 0.00 | −0.09 | −0.26 | −0.14 | −2.61 |

**유동성 관점**
- 미시구조 팩터가 모든 시간 단위에서 우세. 기술지표만으로는 Amihud·변동성을 거의 못 맞힌다 (Kyle's λ는 기술지표에도 변동성 정보가 있어 근접)
- 기술지표를 **더하면** 소폭 개선: 변동성 +0.6~1.7%p, Amihud +0.3~2.7%p → 1월 기대 유동성 모형에 ATR·볼린저 밴드폭 등 추가 고려 가능

**가격 관점**
- 기술지표 부스팅(T2)만 5·15분에서 **작지만 안정적인** 예측력: R² +0.2%, Clark–West p < 0.0001, 연도별 양수 5/6·6/6
- 그러나 하루 30~95회 거래가 필요해 **수수료 후 샤프 −18 ~ −50**. 1시간 이상에서는 예측력 없음
- 1일 봉은 학습 표본이 ~1,000일뿐이라 팩터를 늘릴수록 과적합 (결합 모형이 가장 나쁨)

|---|---|:-:|:-:|:-:|:-:|
| 5분 | 기술지표 부스팅 | +0.23% | 2.06 | −49.8 | 94 |
| 15분 | 기술지표 부스팅 | +0.19% | 1.26 | −17.6 | 32 |
| 1시간 | 기술지표 부스팅 | −0.12% | 1.48 | −5.1 | 11 |

## 5. 분석 중 발견해 바로잡은 함정들

정직한 결과를 위해 검증 과정에서 고친 것들. 보고서·발표에서 **방법론의 엄밀성**을 보여주는 근거로 쓸 수 있다.

| 함정 | 증상 | 해결 |
|---|---|---|
| 체결·호가 메시지 도착 시차 | 유효 스프레드가 음수 | 실측 50ms 지연 보정 (정상 체결 비율 73% → 99%) |
| pandas 불리언 부호 | OFI 회귀 기울기가 음수 | `-(불리언)`이 NOT으로 동작 → 숫자 변환 후 계산 |
| PIN 최적화 정체 | 출발점 그대로 반환 | 모수 재매개화 (로지스틱·로그 변환) |
| 트리 모형의 외삽 불가 | Amihud 예측 R² −17% | '1주 평균 대비 편차' 학습 |
| 쏠린 예측의 방향 적중률 | p = 10⁻²⁴ 가짜 유의성 | Pesaran–Timmermann 검정으로 교체 |
| 추세 있는 팩터로 수익률 예측 | 1일 봉 R² −358% | 가격 모형에는 추세 없는 팩터만 |
| 학습 범위 밖 극단값 | 선형 예측 폭발 | 학습 구간 0.5~99.5% 분위수로 절단 |
| 거래소 점검일의 결측 전파 | 1일 봉 2021년 전체 누락 | 기술지표를 결측 봉 건너뛰고 계산 |
